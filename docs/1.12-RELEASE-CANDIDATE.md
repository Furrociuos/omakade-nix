### Flatpak acceptance

- Flatpak, Flathub, `net.kuribo64.melonDS`, `org.ppsspp.PPSSPP`, and `net.rpcs3.RPCS3` were
  installed for the test.
- melonDS Flatpak launched the DS-Craft homebrew ROM and the recorder closed one PPSSPP-style
  session row: 14 billed seconds. The app emitted only first-run configuration/save lookup
  messages.
- PPSSPP Flatpak started with PPSSPP 1.20.4, but its `host:ro` sandbox could not open the
  host-path PBP because PPSSPP attempted a write/access probe beside the ROM. The launcher now
  refuses host-resident PPSSPP Flatpak files with an actionable error instead of starting a
  guaranteed failure; sandbox-local content remains supported and tested at the argv layer.
- RPCS3 Flatpak reached the same firmware requirement as native RPCS3. It also hit the
  distribution font lookup problem before the firmware check; the Flatpak route is not
  accepted without those runtime dependencies.
