# 1.12 testing, polish, and release-fix plan

This plan freezes the approved 1.12 feature scope. Scope E, the B2-B5 Stats allocation
switch, new product features, publication, tags, and release uploads are out of scope.

## Exit criteria

- The final source commit passes Release and Debug suites.
- 10,000 games and 100,000 sessions have reproducible bounded measurements.
- Staged install, package lifecycle, metadata validation, SBOM generation, Arch audit, and
  Grype pass on the exact packaged commit.
- Native melonDS, PPSSPP, RPCS3, and PCSX2 acceptance has current runtime evidence.
- Flatpak melonDS, PPSSPP, and RPCS3 routes are exercised where legal.
- Remaining Flatpak, Dolphin, physical-controller, gameplay, and maintainer gates are explicitly
  labelled rather than claimed.
- The complete diff receives a final defect review.

## Workstreams

### 1. Candidate and documentation audit

- Verify the worktree, commit graph, release version, changelog heading, README package names,
  and AppStream release entry agree.
- Remove stale statements in the 1.12 implementation/remaining-plan documents.
- Keep `docs/1.12-REVIEW-HANDOFF.md` historical; the final record is
  `docs/1.12-RELEASE-CANDIDATE.md`.

### 2. Performance

- Add a configurable synthetic game count to stress mode without changing production behavior.
- Add a 10,000-game startup/filter measurement.
- Add a 100,000-session database/query measurement.
- Store raw command output and timings in the release evidence directory.

### 3. Release engineering

- Run the complete Release and Debug suites.
- Install into an empty staged prefix and validate the staged application and metadata.
- Build the 1.12.0 Arch package from the exact candidate commit.
- Exercise clean install, smoke, reinstall, removal, and reinstall in a disposable Arch
  container.
- Generate the SPDX SBOM and run Arch audit plus Grype.

### 4. Real-system acceptance

- Keep the completed native melonDS and PPSSPP homebrew sessions, the PPSSPP real-title session,
  the RPCS3 session with supplied 4.93 firmware, and the PCSX2 `Black (USA)` session as evidence.
- Flatpak install, scan, and launch routes are exercised where legal; the PPSSPP host-path and
  RPCS3 runtime limitations remain recorded in the final candidate.
- Dolphin picker/game-change/pause acceptance remains a maintainer gameplay test.
- Physical controller and couch gameplay acceptance remains a maintainer hardware test.

### 5. Final review and handoff

- Review the complete diff from the pre-1.12 base for correctness, data safety, and stale
  source assumptions.
- Fix defects found by review.
- Re-run the affected suites and release gates after every fix.
- Report the exact candidate commit, artifact hashes, passed checks, known limitations, and
  the short maintainer checklist. Do not publish.
